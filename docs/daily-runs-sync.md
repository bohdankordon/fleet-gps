# Синхронизация дневного пробега

`POST /api/devices/runs` web API используется как быстрый provisional-источник dashboard. Ручная синхронизация относится только к текущему календарному дню в timezone из `ApplicationSettings` и сохраняет distance в метрах.

Для `/runs` используется отдельный timeout 45 секунд, поскольку endpoint может отвечать медленнее. Общий timeout остальных eQuGPS endpoint остаётся 15 секунд. Timeout не вызывает автоматический retry и не меняет существующий дневной кэш.

Отсутствующая строка `/runs` не означает нулевой пробег: статистика для такой машины не создаётся и не обновляется. В расчёт `vehiclesWithoutRun` входят все локальные Vehicle, включая disabled. Неизвестные локальному реестру runs пропускаются; дубликаты используют последнюю корректную строку.

Правило качества: `EXACT > PROVISIONAL > ESTIMATED`. RUNS создаёт или обновляет PROVISIONAL, но никогда не перезаписывает EXACT. Mode1 в следующем этапе сможет повысить качество до EXACT. Scheduler пока отсутствует; синхронизация запускается вручную.
