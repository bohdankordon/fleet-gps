# Dashboard API

`GET /api/dashboard/vehicles` читает только локальный PostgreSQL-кэш. Обработка HTTP-запроса не обращается к eQuGPS и не запускает синхронизацию.

Поддерживаются необязательные фильтры `search`, `status`, `activity` и `includeDisabled`. Некорректное известное значение даёт безопасный ответ `400`; неизвестные параметры игнорируются. Список небольшой, поэтому пагинация пока не нужна.

Текущий `serviceDate` вычисляется по IANA timezone из `ApplicationSettings`, а не по timezone машины, на которой запущен backend. Отсутствующая `DailyVehicleStat` означает `no_data`, а не нулевой пробег. Порог минимального пробега сравнивается в метрах; равенство порогу не считается недостаточным пробегом.

Свежесть позиции считается по `fixTime`: доступны `fresh`, `stale`, `missing` и `future`. Будущее более чем на 60 секунд помечается как `future`; меньший сдвиг, устаревшая позиция и превышенный порог свежести считаются `stale`.

Ответ нормализует source/quality в lowercase и не раскрывает внешний device ID, координаты, токены, credentials или сырой ответ БД. Endpoint пока допустим только локально либо в закрытой сети; authentication появится позднее.
