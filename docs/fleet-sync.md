# Синхронизация парка

На этапе 3A список машин является локальным кэшем официального eQuGPS API. Ручная операция синхронизации последовательно получает `GET /devices`, затем `GET /positions` и сохраняет один согласованный snapshot.

`VehicleCurrentState` хранит только последнее нормализованное состояние. Если устройство отсутствует в текущем ответе позиций, его статус, `externalLastUpdateAt` и `fetchedAt` обновляются, но последняя известная позиция не стирается. Машины не удаляются автоматически из-за отсутствия в одном ответе API.

Скорость сохраняется в km/h без UI-округления; `fetchedAt` — единое время получения snapshot. Полная история GPS-точек не сохраняется. Синхронизация пока запускается только вручную; scheduler появится на следующем этапе. Smoke выводит лишь агрегаты и не выводит реальные данные eQuGPS.
