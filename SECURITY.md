# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability. Public
issues are visible to everyone and must never contain production
credentials, tokens, customer or fleet data, exploit material, or other
sensitive details.

Prefer GitHub private vulnerability reporting for this repository when it is
available, and include only the minimum information needed to reproduce the
finding on non-production data.

## Ground rules

- Never include production credentials, tokens, customer or fleet data, or
  exploit material in any public report, issue, or pull request.
- Test reports against local or synthetic environments only; do not probe or
  disrupt production systems.
- Do not exfiltrate, retain, or redistribute data beyond what is required to
  describe the finding.
