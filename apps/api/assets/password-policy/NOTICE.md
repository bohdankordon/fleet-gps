# Password blocklist attribution

`common-passwords.bin` is a derived SHA-256 digest index generated from
`Passwords/Common-Credentials/Pwdb_top-1000000.txt` in
[danielmiessler/SecLists](https://github.com/danielmiessler/SecLists), pinned to
commit `e57f8ad37904658709bceb20b82f22a0e9f2046f`.

SecLists is maintained by Daniel Miessler and contributors and is distributed
under the MIT License. The upstream filename and SecLists history attribute the
source corpus to the [Pwdb project](https://github.com/ignis-sec/Pwdb-Public).
Consult the pinned upstream repository for its complete license and attribution
notices when updating this derived artifact.

The upstream plaintext passwords are not redistributed in this repository.
